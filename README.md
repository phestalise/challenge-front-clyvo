# 🐾 CLYVO VET

Sistema de gestão da saúde pet desenvolvido para o Challenge FIAP 2026 em parceria com a Clyvo.

---

# 📌 Sobre o Projeto

A CLYVO VET é um aplicativo mobile criado para auxiliar tutores no acompanhamento da saúde dos seus pets. O sistema permite cadastrar animais, registrar consultas veterinárias, controlar medicações e acompanhar informações importantes em um dashboard intuitivo e moderno.

---

# 🚀 Funcionalidades

* Login e cadastro
* Cadastro de pets
* Controle de consultas
* Controle de medicações
* Dashboard de saúde
* Calendário de eventos
* ChatBot de suporte

---

# 🛠️ Tecnologias Utilizadas

* React Native
* Expo
* TypeScript
* Node.js


---

# ⚙️ Como Executar

## 1️⃣ Clonar o projeto

```bash
git clone https://github.com/seuusuario/clyvo-vet.git
```

## 2️⃣ Entrar na pasta

```bash
cd CLYVO-VET
```

## 3️⃣ Instalar dependências

```bash
npm install
```

## 4️⃣ Executar o projeto

```bash
npx expo start
```

# 🗄️ Banco de Dados

O banco foi desenvolvido em Oracle Database utilizando Oracle SQL Developer e Oracle Data Modeler.

Principais entidades:

* Usuário

* Consulta
